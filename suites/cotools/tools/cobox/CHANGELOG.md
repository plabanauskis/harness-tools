# Changelog — cobox

Notable changes to cobox. Releases follow [Semantic Versioning](https://semver.org).

## 1.0.0 — 2026-08-26

- Add a sysbox container for autonomous Codex, with project and state mounted at
  their host paths.
- Detect official npm and native Codex installations and mount them read-only.
- Add build, doctor, uninstall, ports, caches, authentication, and terminal tint.
